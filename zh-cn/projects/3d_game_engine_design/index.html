3D 游戏引擎

一个基于 C++ 和 SDL3 实现的 3D 游戏引擎，用于探索实时渲染、动画系统与引擎架构。

项目概述

这是一个使用 C++ 与 SDL3 构建的自研 3D 游戏引擎。我通过它实践实时渲染、资源加载、动画、碰撞、多线程、性能分析与玩法系统在同一运行时中的协作方式。下面按照开发阶段，从最初的渲染管线一直展示到最终的 Q*bert 项目。

1. 渲染基础

三角形

  • 使用顶点缓冲与着色器搭建基础渲染管线
  • 封装简单几何体的绘制辅助类

网格渲染与相机

  • 使用顶点与索引缓冲实现网格渲染
  • 添加物体变换与相机系统

深度与纹理

  • 引入 z-buffer，实现正确的深度测试
  • 添加 UV 坐标并在着色器中采样纹理

2. 光照与场景架构

材质与 Phong 光照

  • 添加材质系统与点光源
  • 构建结合光照、材质和纹理的 Phong 着色器

期中着色器

  • 实现 Lambert 漫反射
  • 扩展 Half-Lambert，使明暗过渡更柔和
  • 添加边缘光以增强物体轮廓

模型、资源与关卡

  • 构建资源管理器，实现已加载资源的复用
  • 实现 JSON 关卡加载与基于组件的场景对象

3. 动画与物理

骨骼动画

  • 实现 Skeleton、BoneTransform 与 Animation 类
  • 添加用于动画模型的蒙皮着色器

碰撞系统

  • 实现 AABB 与线段检测
  • 为相交检测编写单元测试
  • 整合平台碰撞与角色掉落行为

4. 性能与渲染完善

任务系统与性能分析

我实现了计时器与性能分析工具，将追踪数据导出为 JSON，并构建了带多线程工作线程的任务管理器。下面分别展示启动资源加载与并行动画更新。

启动阶段：着色器编译以及关卡、网格和纹理加载。

运行阶段：动画任务分配至多个工作线程，并在主线程继续渲染前完成同步。

法线贴图

  • 扩展输入布局以支持切线数据
  • 加入法线贴图支持与对应着色器

Bloom 后处理

  • 将场景渲染至离屏目标
  • 提取高亮区域并使用多分辨率高斯模糊
  • 每帧将 Bloom 结果混合回原始画面

5. 最终整合：Q*bert

期末项目将引擎的各项系统整合为一个完整的网格移动街机游戏。

  • 四方向跳跃与方块状态变化
  • 移动障碍、敌人行为以及胜负状态
  • 整合关卡加载、动画、碰撞、摄像机、光照与玩法系统

我的工作内容

  • 实时渲染系统与 HLSL 着色器管线
  • 场景、资源、动画、碰撞与玩法系统
  • 多线程任务执行与性能分析流程
  • 使用 Visual Studio 与 Chrome Tracing 进行图形和性能调试
  • 应用于实时系统的线性代数与向量数学
