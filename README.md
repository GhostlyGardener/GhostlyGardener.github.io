# GhostlyGardener.github.io

Personal portfolio site for Ghostly Gardener, focused on game development, gameplay programming, engine work, and music.

This site is built with `multi-language-al-folio`, a multilingual Jekyll theme.

## Local Preview

The project uses Docker for local development.

```powershell
docker compose up
```

Open:

```text
http://localhost:8081
```

The container runs Jekyll with live reload through `bin/entry_point.sh`.

## Content

- `_pages/en-us` and `_pages/zh-cn`: top-level pages
- `_projects/en-us` and `_projects/zh-cn`: portfolio projects
- `assets/img`: images and project media
- `games`: playable web game builds
